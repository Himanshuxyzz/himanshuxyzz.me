## What this blog is about

This blog is something I've always wanted to have and I was thinking about it since long. It's been a long time since I have been actively following many developer blogs and one thing that I have learned from these blogs is the fact that **self branding is very important**, specially for developers No matter if you create websites or do photography or run a shop, **if you exist on web then you need to brand yourself first** to successfully promote yourself or any of your work. And I think the best way to go about it is by creating a personal website which shows all your work/products in one place, which is why I created this website.

> To sum it up, if I find it interesting, it's most likely to end up on this blog.

So apart from sharing projects I work on and the crazy challenges I take, this blog is also about everything that interests me, also interesting links I find on web.
