A direct-to-consumer shopping app that lets users browse a curated catalog of wooden furniture, complete with high-quality visuals, detailed descriptions, a secure checkout process, and order tracking—all optimized for mobile.

### Key Features

- **Curated Catalog**: Browse high-quality wooden furniture with detailed descriptions and visuals.
- **Secure Checkout**: Seamless and secure payment process for a smooth shopping experience.
- **Order Tracking**: Real-time updates on order status from purchase to delivery.
- **Mobile Optimized**: Smooth performance and intuitive design tailored for mobile users.
