## Overview

Carlust is a full-featured car rental application built for Gigbei. As the sole React Native developer, I architected and developed this app from concept to deployment, handling the entire mobile development lifecycle.

## Key Features

- **Robust Navigation System** : Implemented using React Navigation with nested navigators for seamless user flow across booking, payments, and profile sections
- **Advanced State Management**: Integrated Zustand with persistent data caching via AsyncStorage for offline functionality
- **Performance Optimization**: Achieved through lazy loading components and FlashList implementation, reducing render times by 30%
- **Secure Payment Gateway**: Integrated payment processing enabling real-time booking transactions and automated rental confirmations

The application was successfully deployed to the Google Play Store and serves as a flagship product for Gigbei.
