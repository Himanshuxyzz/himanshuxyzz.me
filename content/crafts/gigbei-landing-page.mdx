## Overview

Developed a modern company website for Gigbei using Next.js with server-side rendering for improved SEO and performance. This project showcases the company's services, products, and brand identity with a sleek, professional design.

## Key Features

- **Server-Side Rendering**: Implemented Next.js SSR for optimal performance and search engine visibility
- **Dynamic Content Management**: Built using MDX files for blog posts and project showcases, enabling non-technical team updates
- **Responsive Design**: Created a fully responsive interface that adapts to all screen sizes while maintaining visual integrity
- **Modern UI/UX**: Implemented contemporary design principles for enhanced user engagement and brand representation

The landing page serves as the primary digital presence for Gigbei, contributing to lead generation and brand awareness.
